# ImageChat Local — beta

**試用・評価用のテスト版です。安定版ではありません。** このリポジトリは画像生成モデルそのものではなく、既存のモデルをComfyUI経由で利用するアプリです。

動作報告、不具合、使いにくい点、改善案をGitHub Issuesへお寄せください。「動いた」という報告も歓迎します。いただいた内容を確認し、再現・対応できるものから可能な範囲で修正し、アップデートしていく方針です。すべての要望への対応や修正時期はお約束できません。

修正案のPull Requestも歓迎します。報告方法はCONTRIBUTING.mdを参照してください。モデル・Workflowの特性による生成品質と、アプリの不具合は切り分けて確認します。

日本語の会話、参照画像、Sketch、Mask、ポーズ人形で画像を生成・編集するWindows向けローカルアプリ。Qwen-Image 2.1対応の既存ComfyUIへ接続します。Qwen公式製品ではありません。

モデル、ComfyUI、Python本体、個人の画像・履歴は含みません。これは実行ソース付きの配布候補版です。コードの公開ライセンスはLICENSE-STATUS.mdを参照してください。

## はじめに

1. ZIPを任意の書き込み可能なフォルダへ展開。ZIP内から直接実行しないでください。
2. Python 3.10以上を https://www.python.org/downloads/windows/ から導入し、`python`コマンドが利用できるようにします。
3. `Setup.bat`を実行。アプリ専用`.venv`にPillowを導入します。この段階でPyPIへ通信します。
4. Qwen-Image 2.1対応のComfyUIと必要モデルを用意します。下記MODELS.mdを参照。
5. `Start.bat`を実行。ブラウザで http://127.0.0.1:8791 が開きます。
6. 左下「設定・接続」でComfyUIのURLを指定して接続確認。まずEnhancer OFFで小さい画像を1枚生成してください。

ComfyUI停止中でも初期画面を開けます。必要Nodeが不足する古いComfyUIは利用できません。自動更新・自動Node導入はしません。別のアプリが8791を使用している場合は `powershell -File .\Start.ps1 -Port 8795` 等で変更します。

アプリのPythonとComfyUIのPythonは別環境です。既存環境のモデル移動やパッケージ変更は不要です。

## 0.1.1の変更

画像ライブラリを追加しました。左側の「画像ライブラリ」から生成・添付画像を検索し、プロジェクト・チャット・お気に入りで絞り込めます。画像を選ぶと元のプロンプト、Enhancer後の指示、保存された生成設定を確認できます。添付画像は参照として使用した指示を区別して表示します。元画像の作成プロンプトが未記録の場合は復元しません。

入力欄を横へ広げ、高さと余白を抑えました。自動Enhancerの完了後は英文を自動展開しません。

## 基本操作

- 新しい絵：画像を添付せず、日本語で送信。
- 編集：画像を添付するか、生成画像の「この画像から編集」を押して送信。
- 複数参照：添付順が画像番号。画像タグボタンで番号を入力できます。並べ替え後は指示の番号も確認してください。
- Canvas：Sketch、Mask、2Dポーズ、キャンバス拡張。元画像を保持し、新しいGenerationへ保存します。
- 被写体移動（試験）：画像を1枚、または移動先を画像1・移動元を画像2として2枚添付し、Canvasの「被写体を移動」で赤枠（移動元）と緑枠（移動先）を指定して生成します。元画像は上書きしません。Mask・Sketch・Pose・Canvas拡張との同時使用、3枚以上の参照は未対応です。
- チャットはプロジェクトとフォルダで整理。過去の画像から別の分岐を作れます。
- 画風は指定なし／イラスト／フォトリアル。参照画像の画風を完全固定する保証はありません。
- 指示の整理は詳細設定の自動／OFF／ON。自動はイラストの参照ポーズ・キャラ置換・上下アングルをルール判定。公式のローカルEnhancerで数分かかることがあります。モデル不足時はOFFにするか導入してください。
- 停止は生成カードから。ComfyUI側にジョブ単位キャンセルAPIが必要です。
- 完全終了は「設定・接続」から。タブを閉じるだけではサーバーは終了しません。

## 保存と通信

`data/`に画像、チャット、設定、ログを保存します。バックアップはアプリ終了後にdata全体をコピーしてください。更新はUPDATING.mdの別フォルダ方式を使用します。Import-Data.ps1は既存の移行先を上書きせず、旧データを残します。公開するZIPやGitへdataを入れないでください。

アプリは127.0.0.1で待ち受けます。画像・指示を外部AIへ送信する機能はありません。ComfyUIやCustom Node内部の通信は各実装に依存します。

## ComfyUIの自動起動（任意）

`comfy-launch.example.json`を編集し、自分のComfyUIディレクトリ・Python・引数を指定。`data/comfy-launch.json`へ保存すると次回から未起動時に直接起動します。設定URLをアプリ接続先と一致させてください。Stability Matrixの起動は不要です。アプリ終了時にComfyUIは停止しません。

## 配布版と手元の開発版の違い

- モデルの「自動」は全画風で公式モデルを選択。追加モデルを要求しない構成です。イラスト編集は推奨CFG3。
- NoctQ等は選択肢のみ。利用者が配布元の条件を確認し、別途導入します。
- 高速4stepと拡張補助LoRA方式は初回配布対象外。標準生成と標準Canvas拡張は利用できます。
- 追加Node、転載Workflow、テスト画像、個人データは同梱していません。

## 制限・検証

これはベータ版です。独立環境でのセットアップ・起動・回帰テストの結果はVALIDATION.mdを参照。別PCでのGPU実生成は未確認です。VRAMの最低保証値は未測定です。ComfyUI、モデル、Nodeの組合せにより結果と所要時間は変わります。

被写体移動は同じ画風のイラスト2枚で実生成を確認しています。写真の背景へイラスト人物を移すと、配置はできても人物のイラスト調が残る場合があります。画風の完全一致は保証しません。

Qwen側のライセンスは研究・評価用途を規定しています。無料配布であることだけで、すべての用途が許可されるわけではありません。各モデルの条件を確認してください。アプリのコードの条件とモデルの条件は別です。

不具合報告にはOS、GPU/VRAM、ComfyUIバージョン、モデル名、操作手順を添えてください。履歴DB、私的な画像、トークンをそのまま公開しないでください。
